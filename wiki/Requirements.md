# Requirements

← [Home](home)

---

| Requirement | Version |
|-------------|---------|
| Magento 2   | 2.4.x (framework 102.x – 103.x) |
| PHP         | 8.1, 8.2, or 8.3 |
| Composer    | 2.x |
| cURL        | Any version bundled with PHP |

> PHP 7.x is no longer supported as of `innosend/magento2` 1.1.0.
